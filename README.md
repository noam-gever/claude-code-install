# מתקינים את קלוד קוד

דף מקדים לקורס קלוד קוד של **נעם AI**.
מלווה מתחילים גמורים בהתקנה, צעד אחר צעד, בלי טרמינל ובלי ידע קודם.

**הדף החי:** https://noam-gever.github.io/claude-code-install/

## איך זה עובד

מסך אחד בכל פעם, בלי גלילה. בוחרים מק או ווינדוס, וכל המסלול משתנה בהתאם.
בכל שלב: סרטון, צעדים ממוספרים, וכפתור **"נתקעתם? יש כאן פתרונות"** שנפתח במקום.

## לשנות טקסטים

הכל בקובץ אחד, `index.html`, בתוך תגית `<script>` בסוף.
מחפשים את השם ומשנים את הטקסט בין הגרשיים.

| מה לשנות | איפה לחפש |
|---|---|
| קישורי הסרטונים | `const VIDEOS` |
| הקישור לשיעור הראשון | `const LESSON` |
| שלב הגיט | `const GIT` |
| התקנת קלוד | `const INSTALL` |
| התשלום | `const PAY` |
| ווינדוס: התקנה+תשלום | `const SETUP` |
| הבדיקה האחרונה | `const READY` |
| דרישות המערכת | `const SYS` |
| גווני הרקע בכל שלב | `const MOOD` |

בכל שלב: `t` הכותרת · `acts` הצעדים · `fx` התקלות · `note` שורת ההערה · `warn` האזהרה · `win` שורת ההצלחה הירוקה.

**אחרי שינוי:** `git add -A && git commit -m "עדכון" && git push`
הדף החי מתעדכן תוך דקה.

## גרסה-2.html — 07/09/2026

עותק נפרד של `index.html` עם התיקונים החדשים. **`index.html` לא נגעתי בו** — הוא עדיין הגרסה שבאוויר, ואפשר לחזור אליו בכל רגע.

מה שונה:
- **מסך פתיחה** — כותרת "יאללה, מתקינים את קלוד", הודעה פועמת "חשוב מאוד להתקין את התוכנה לפני ההדרכה", "על איזה סוג מחשב אתם?" מוגדל ופועם, תיבת "שימו לב" עם המנוי בתשלום. שורת "חיבור לאינטרנט" הוסרה.
- **"שלב X מתוך Y"** — הוגדל לגלולה כתומה בולטת (`.eyebrow .mono`).
- **הערת המחיר** — הוגדלה לתיבה משלה עם אייקון (`.note`).
- **שאלות** — ניסוחים מתוקנים בווינדוס ובמק (הכל בתוך `const GIT` / `const INSTALL` / `const PAY`).
- **באג שתוקן** — בתיבת השאלות, תשובה של שאלה בתחתית הרשימה נפתחה מחוץ לשטח הגלילה ונראה שכלום לא קרה. עכשיו התיבה גוללת אליה.
- **מסך סיום** — "התקנתם את קלוד. עכשיו אתם מוכנים להדרכה." הכפתור "לשיעור הראשון" הוחלף בכפתור ירוק לקבוצת הוואטסאפ (`const WHATSAPP`).
